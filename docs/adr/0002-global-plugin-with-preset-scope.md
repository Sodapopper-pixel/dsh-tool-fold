# 插件挂全局，用生效预设名单限定范围，不自带预设

最初的设想是插件注册一个自己的预设，只在那里折叠工具。放弃这条路的直接原因是复刻标准预设的代价：`PresetDefinition` 没有继承或差异字段，要"包含标准预设会注册的工具"只能抄一份完整行列表，而这会带来上游改动不合并造成的静默漂移、漏抄 `isolate` 导致整个预设装载被拒、以及第三方包复刻 `@deepseek-ai/dsh-*` 行时的模块解析基准不同。

改为插件在 profile 里挂全局一行，每个组的配置里写自己的生效预设名单；运行时按当前会话的预设判定命中，命中才在该会话安装查询工具并折叠。模型可见的效果与"自带预设"等价，代价是配置分散在插件设置里而不是预设 YAML 里。
