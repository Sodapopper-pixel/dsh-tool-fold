# 组配置存插件自己的存储，不写进 cordis.yml

DSH 插件惯例是把随部署变化的选项做成 schemastery `Config`、由 cordis.yml 提供，本插件反其道而行：组列表、工具绑定、生效预设名单存进插件自己的存储命名空间，`Config` 只留引导级选项。

这些数据是被反复编辑的用户数据，形状是"组 → 工具集合 × 预设名单"的嵌套结构，手写 YAML 维护成本高；而且设置页拿不到写回宿主配置文件的通道，若数据留在 `Config` 里，用户在页面上改完无法落地。代价是这份配置不随 profile 的 cordis.patch.yml 一起迁移，换机器要单独搬。
